# MediVoice AI — Portfolio Summary

## Project title
**MediVoice AI — Intelligent Patient Record Retrieval Through Voice AI**

## Portfolio status
**Active Development — Phase 0.2 MVP**

## One-line description
A voice-enabled healthcare AI prototype that lets authorized clinical users retrieve structured synthetic patient records through natural-language commands with verification, RBAC scaffolding, FHIR-oriented resources, spoken responses, and audit logging.

## Short portfolio description
MediVoice AI explores a voice-first workflow for clinical record retrieval. A clinician can ask for a patient's latest labs, allergies, medications, diagnoses, appointment, or summary; the system resolves the patient, requires DOB verification, retrieves the requested structured clinical resource, returns a controlled conversational response, and records the access event.

The current MVP uses synthetic patient data only. The conversational layer is intentionally separated from the clinical source of truth so that patient facts come from deterministic structured records rather than being generated by the AI layer.

## Key capabilities
- Voice and text patient queries
- Browser speech-to-text and text-to-speech
- Intent recognition for common record-retrieval requests
- Patient matching by full name or MRN
- DOB verification before record release
- Demo RBAC roles and authorization checks
- FHIR-oriented Patient, AllergyIntolerance, MedicationRequest, Condition, Observation, and Appointment resources
- Structured audit trail
- FastAPI/OpenAPI backend
- Dockerized frontend and backend
- Automated Pytest coverage

## Technology
Python · FastAPI · Pydantic · REST/OpenAPI · FHIR-oriented modeling · JavaScript · HTML/CSS · Web Speech API · SpeechSynthesis · Pytest · HTTPX · Docker · Docker Compose · Nginx · Uvicorn

## Architecture summary
`Voice/Text → Speech-to-Text → Intent Detection → RBAC → Patient Resolution → DOB Verification → Structured Clinical Retrieval → Controlled Response → Text-to-Speech → Audit Trail`

## Demo script
1. Click **Voice**.
2. Say: **“Retrieve Juan Dela Cruz latest laboratory results.”**
3. MediVoice asks for DOB verification.
4. Say: **“November 4 1978.”**
5. MediVoice displays and speaks the synthetic results and records the access event.
